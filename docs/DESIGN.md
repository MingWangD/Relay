# Relay macOS 桌面设计规范

更新：2026-10-05。当前采用 TypeScript、Vite、xterm.js，单页对话布局。使用说明见 [README](../README.md)，行为边界见 [功能与验收口径](REQUIREMENTS.md)。

## 信息与布局

- 左栏宽 260px，可折叠；只列未归档历史，提供新建、切换、归档和确认删除，按最近活动显示摘要、运行状态和提醒。已归档对话通过右上角独立管理弹窗查看与取消归档。
- 顶部入口为项目、项目右侧“＋”、Agent、更多。“＋”打开小型文件夹菜单，支持 Escape／点击外部关闭；选择器等待时禁用重复点击，不增加路径输入表单。用户输入需求，团队处理内部计划；不增加角色分配、任务表单或人工计划批准。
- 页面占满 100dvh，桌面两侧留 24px，取消聊天 780px 限宽。顶部栏、聊天、底部操作区分开；聊天独立滚动。
- 底部顺序为待处理请求、运行控制、输入框。请求区最高占窗口 25%，输入区最高 30%；超出后各自内部滚动。
- 用户消息靠右，团队进展、询问靠左；最终结论置于协作区下方，以受控 Markdown 排版；按持久化状态展示，不预置演示进度。
- 每项需求的“查看协作过程”默认折叠，按需显示子任务、成员消息与真实终端。1–4 个终端两列，5–8 个每页最多四个。
- 当前范围为 macOS 桌面，产品目标为可独立启动的 Mac App；保留桌面窗口缩放兼容。

## 配置与权限

- “选择 Agent”按类型选数量，Codex／Claude 每名成员选模型和强度，Anti 只选完整模型 ID。默认沿用 CLI 默认，能力已知时联动强度；模型列表显示 CLI 返回的全部名称，不提供自定义 ID 输入；目录失败保留上次列表、默认或已保存模型并提供重试。目录加载完成时更新稳定控件，保留焦点与当前选择。
- 团队权限为完全访问／原生审批，新团队默认完全访问。说明完全访问包括项目外文件，并受系统及组织限制。
- 配置仅空闲时保存；执行、排队、恢复期间禁止修改。保存不触发模型调用，变更用于下次启动。
- 三类终端主栏只显示模型与英文强度；成员、状态、操作保留。权限、原生确认与变化放在“设置详情”，缺少回报不宣称生效。

## 请求与终端

- 摘要只显示可判断的操作、文件／命令和授权范围；不显示原始 JSON、协议方法、会话 ID 或 schema。
- 支持的 Codex 请求提供批准／拒绝；未知请求和 Anti／Claude 原生提示提供可读提醒与原终端入口。
- 权限提醒依据当前画面更新，重绘后清除旧提醒；工具活动、权限等待和轮次结束分别展示。
- 启动无会话回报时显示“已启动，等待会话确认”；30 秒无 Hook 或有效 MCP 活动显示诊断，保留进程和终端。
- 模型连接失败显示简短原因与处理入口，不把重试误标为完成。键盘／粘贴仅在人工接管时接收；退出接管仍可滚动。普通缓冲使用 xterm 本地历史；全屏模式使用认证且受限的滚轮通道：有鼠标追踪时发送原生鼠标报告，否则发送有界上下方向键，保留应用光标模式。触控板微小位移累积，反向时清除余量；每次最多十步。后续有效工具活动清除 Claude 重试提醒。
- 终端仅在可见且尺寸有效时拟合；折叠、分页、放大、窗口变化合并到一帧，无尺寸变化不重复拟合。真实列／行同步给 PTY，隐藏终端不能用零尺寸改写原生画面。
- 画面快照由服务端 VT 终端按当前原生列／行序列化，最多保留 5000 行历史，包含 ANSI 光标与缓冲模式；不截断原始输出尾部后重放。首次打开按需请求，重连重新请求；等待解析完成后捕获序号，先恢复原生尺寸与快照，再按代次／序号接续增量。缺包重新取快照；保留真实 CLI 文字。

## 交互与视觉

- 系统字体、中性浅色／深色主题、细边框、紫色焦点；终端保持深色。颜色与间距使用 CSS 语义变量，状态同时给文字。
- 原生 dialog、可访问标签、键盘焦点、关闭后焦点返回。Enter 发送、Shift + Enter 换行，中文组合输入不发送。
- 状态更新不抢输入焦点或历史阅读位置；折叠、尺寸变化、主题切换保留当前 xterm 实例。服务重启不重新附着旧 PTY。
- 删除自动跟随与投递定位。只有“查看最新”移动聊天视图；稳定节点更新，按聊天保存草稿、锚点及展开状态。更新消息计数不能关闭成员交流。
- 更多收纳主题、高级执行设置、历史与报告导出。代码成果才显示“查看改动”；失败、权限和回写冲突明确说明。

## 参考来源

视觉与可访问交互参考 [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 的中性表面和文字层级、[ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的简洁与焦点指导、[shadcn-admin](https://github.com/satnaing/shadcn-admin) 的语义主题与控件。沿用现有 SVG 和技术栈；运行不依赖这些参考技能。

归档管理：左侧只列未归档历史。右上角“已归档对话”打开独立宽弹窗，提供搜索、时间排序、项目标题／数量、日期、打开、取消归档和确认单条／全部删除。沿用主题色与原生 dialog 键盘行为，不展开侧栏或定位当前聊天。

项目空间：`local-picker.ts` 通过固定 AppleScript 打开 macOS 原生文件夹选择器，路径不拼入脚本。`local-projects.ts` 按规范 Git 根目录复用本机控制台；新增项目保存于主数据目录下的 `projects/<摘要>/`，使用原有单项目引擎、独立凭据和进程锁。`POST /api/project-folder` 仅允许控制台用户并校验源聊天，返回导航链接但不将凭据存入持久化请求结果。父服务管理全部子控制台关闭；每个项目保持自己的需求队列及并发限制。
