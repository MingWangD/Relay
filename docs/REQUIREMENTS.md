## 聊天与阅读补充

- 聊天新建复制团队配置与独立身份；切换无模型调用，所有聊天共用项目串行队列。
- 侧栏只显示未归档历史；右上角“已归档对话”打开独立管理弹窗，提供搜索、时间排序、日期、打开、取消归档和确认删除。
- 旧记录迁入现有对话；归档可恢复，删除需确认且只删 Relay 记录。执行、排队、停止、检查和恢复中的聊天不能归档／删除。
- 同一成员所有阶段及后续需求保持原生 ID。独立任务／评审工作区与非作者约束保留，评审不要求全新上下文。
- 聊天、终端保持手动阅读；更新不关闭展开、不重建 xterm、不抢输入焦点。总结位于终端区下方，HTML 不执行，原文可导出。
- 新增 conversations.test.ts、reading.test.ts、终端滚轮和聊天历史浏览器回归覆盖上述行为。

## 验收规则

1. 排队、适配器接收、协作工具活动、消息确认与任务通过是不同事实。终端文字、动画和权限提示不能证明任务完成。
2. 原生模型／强度回报才能标记确认生效；传入参数只证明已配置。别名解析或设置变化应可见。
3. 已识别独立测试失败不能算完成；没有识别入口必须说明“未执行自动测试”，区分 Agent 自行检查与平台独立检查。
4. 分析不制造代码成果提交；纯分析原目录审计不能被新基线掩盖。审计无法观察项目外或已恢复的瞬时修改。
5. 完全访问允许读写项目外文件、执行命令和联网；worktree 及回写保护不能限制 Agent 直接操作其他目录。系统权限和组织限制仍有效。
6. 不能跳过的登录、风险声明、信任和用户问题保留人工入口；产品不猜测按键批准原生提示。
7. 浏览器夹具与 CLI 协议替身不能证明真实模型闭环。当前三类 CLI 代码协作和后续分析通过；Claude 重试后恢复；具体参与角色见验收记录。
8. 服务重启后不能重新附着旧 PTY；Anti 空闲接续可能重启进程并重绘，不宣称同进程无感注入。
9. 同一聊天跨项目协作、公网协作、8 个真实模型长时间压力和统计性能尚不在已验收范围。

## 本机项目选择

项目名称右侧“＋”打开文件夹菜单，入口为“在此电脑上选择文件夹”。macOS 原生选择器取消不变更状态；系统授权失败提供原因并可重试。仅用户认证接口可触发选择器，同窗口重复请求被拒绝；切换不调用模型。

不同 Git 根目录使用独立项目空间、数据库、工作区、凭据与本机端口，保留原项目聊天和执行；新空间复制所选聊天团队设置，但新建成员身份，不复制原生会话绑定。重复选择复用空间，重启后重新打开复用持久化历史。项目内子目录规范化为 Git 根目录。项目须已有 Git 提交，不自动初始化 Git；单聊天跨项目协作不在范围内。主服务关闭所有所管理项目。

## macOS 安装包边界

原生壳目标为 macOS 13+、arm64；当前官方 Node 24 开发安装包实际要求 macOS 13.5+，脚本从 Mach-O 读取下限写入 plist。App 自带独立 Node、生产依赖、Agent Hook、PTY helper 和 Sparkle，用户无需另装 Node。当前仅 ad-hoc 开发签名，生产发布和更新仍待签名、公证及 appcast 验收。WKWebView 只接受拥有服务和经其用户认证的项目空间 origin，不接受任意本地页面或 file URL。

## 0.1.5 图片及工作区

- 附件限额、上传状态、聊天归属、SHA-256、原图持久化和原子绑定必须保持；缺失或损坏不能伪装识图成功。
- 未知视觉能力需明确调用诊断；没有已确认视觉成员时保留草稿。其他成员只获得结构化团队分析。
- 运行中补图不得丢失或跳过识图，补图完成后重新规划并保留已有任务和原生 ID；总结期间补图不得被旧总结提前结束。
- 日期分组只适用于新布局；已保存路径和 `sessionCwd` 优先，不能迁移执行中工作区或改变原项目 Git 身份。
