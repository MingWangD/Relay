## 0.1.5 图片、工作区与审查修复

- 原生 App 中选择隔离 Git 项目，Codex gpt-6.1-sol（high）实际查看首张随机图片；通过 ⌘V 粘贴第二张图并补充需求，两图答案准确、结构化读取及分析批次完成，后续分析任务与总结完成。图片答案不在文件名或提示词中；未运行 OCR。成员原生 ID 全程保持，原项目 HEAD、分支、索引字节及业务文件与开始基线完全一致。
- 首轮视觉成员准确识图后直接提问，漏交结构化分析。保留失败并补 submit-before-ask 顺序校验；同一会话修复后继续补图。该校验及总结中补图、规划前置门槛由源码回归保护；没有把一次普通文本答复当作平台识图完成。
- Antigravity gemini-3.8-flash-medium 在独立诊断中用 MCP 图片内容块正确识别随机图，一次后续补图正确，原生 ID 保持；不是原生 App 团队混合协作验收。DeepSeek deepseek-flash 未确认：原生目录信任提示导致超时，未自动批准、未标记 unsupported。补充诊断终端人工入口，浏览器夹具验证显式人工接管与完成后禁用；尚未在原生 App 重新处理 DeepSeek 信任提示。
- 正常退出重启后图片大图可读、聊天及成员身份保持。真实原生菜单导入包含上述已发送原图、聊天和成员绑定的完整隔离数据；导入前生成目标备份，源目录逐字节未变。导入退出再启动，图片预览、SHA-256、完成状态及原生 ID 保持，没有自动模型调用。
- 原生文件选择、图片粘贴、普通文字复制粘贴及正常退出通过。拖入、多图、图片上传失败重试、仅图片、补图批次、草稿保留、原生剪贴板补充桥模拟由浏览器／服务夹具覆盖；此版未重新完成真实中文输入法候选操作，相关浏览器回归通过，0.1.4 原生结果保留。
- 新工作区按本机创建日期分组、使用短 ID；旧布局与已绑定启动目录保持。回归覆盖新日期、旧路径复用、任务版本和原项目 Git 身份。已存在的验收目录继续旧布局，不将截图中的旧路径改名。
- 行内 markdown-it 保留 URL，覆盖下划线、星号、括号、格式化链接标签、转义、代码、危险协议及原始 HTML；远程图片不渲染。现有块级标题、稳定节点、阅读选区和折叠行为保留并通过浏览器回归。
- 快照流式哈希两遍检查、符号链接、执行权限、变化／删除、索引保护及失败回滚通过。大文件指纹一致；实测内存下降、小文件成本增加。状态缓存防御性克隆、字符串脱敏、事务失败不广播、重启恢复及人工接管 JSON 回归通过。完整阶段数据见 [PERFORMANCE](PERFORMANCE.md)，没有宣称消除 SQLite／广播的全量成本。
- 类型检查、96 项服务／打包、35 项浏览器夹具、生产构建、Swift release、4 项 Swift 实文件导入及包内 Node／PTY smoke 通过；包内 Hook 为夹具，不等于模型结果。附件数据复制与旧数据兼容由服务测试覆盖；恢复用持久化图片批次，不自动重跑旧需求。

- 人工接管的 JSON 解析错误来自对已序列化 JSON 做凭据脱敏，替换破坏转义。改为先解析结构，仅脱敏字符串值，保留原始持久化文本。带引号、反斜杠的模型输出回归先失败后通过；浏览器实际接管按钮切换成功，无 JSON 提示。本地历史数据只读重放同样复现旧错误，新序列化通过；没有迁移或覆盖用户数据库。
- 类型检查、生产构建、82 项服务／打包检查、31 项浏览器夹具、4 项 Swift 实文件导入检查通过。Swift release、App／DMG 构建与包内真实 Node／PTY smoke 通过；Hook 为夹具，未调用模型。
- 正式原生检查使用经核对的独立数据目录与明确区分的测试 App；结束后测试服务退出。一次测试启动缺失隔离环境，已退出并修正启动器，重新核对后完成验收；没有自动恢复历史任务。

## 0.1.3／build 4 历史验收

验收环境：Apple Silicon arm64、macOS 26.4。发行边界 macOS 13.5+；未完成 macOS 13.5 实机或干净机器验收。以下真实模型与夹具检查分别记录。

### 自动检查

- 类型检查、生产构建通过。
- 服务／打包检查 81 项通过；浏览器夹具 27 项通过；Swift 实文件导入保护 4 项通过。
- Swift release 编译、arm64 App／DMG、资源及签名完整性检查通过。签名为 ad-hoc，未公证，生产自动更新关闭。

### 原生与数据

- 中文项目／数据导入选择器显示本机系统语言；隔离英语进程选择器检查来自 0.1.2，未修改系统设置。
- 真实原生菜单导入包含两段主项目聊天及两段独立子项目聊天、消息和成员绑定的隔离数据。退出重启后选择子项目，聊天、消息与原生 ID 保持；源目录逐字节未变；原目标备份保留。选择本身未启动模型。
- 取消导入已有真实 UI 检查；源服务存活、目录重叠、复制失败及回滚由 Swift 实文件检查覆盖。
- 精准终止隔离 App 的 WebContent 后，原生提示出现。“稍后”后通过查看菜单重新加载，以及直接“重新加载”，均返回同一子项目。真实协作已完成页面也经故障恢复，需求状态、运行数量和原生 ID 保持。
- 独立原生标题栏支持拖动；窗口按钮不遮挡网页。窗口位置与尺寸保存、全屏退出重启恢复已检查。图标包含 SVG、1024px PNG 和多尺寸 ICNS，关于窗口与 Finder 已检查；Dock／应用切换器仍需人工视觉确认。

### 真实三类 CLI 协作

在新建隔离 Git 项目中，由 App 原生选择项目并配置 Codex、Antigravity、Claude 各一名。验证模型分别为 gpt-6.1-sol（low）、gemini-3.8-flash-medium、deepseek-flash（high）；模型可用性受本机 CLI、账号及服务配置影响。

- 一轮代码需求：只新增限定文件，独立测试、非作者交叉评审和安全回写完成；三名成员均参与。平台两条测试退出状态为 0，成员另有真实测试证据。
- 同一团队后续分析需求：四项累计任务均完成，成员原生 ID 不变；分析只交依据，无新平台自动测试，不把分析结果称为测试通过。
- 原项目 HEAD、分支和暂存内容保持。首轮 Git 只读检查刷新了索引统计缓存，已使用 GIT_OPTIONAL_LOCKS=0 修复并增加实际索引字节回归。
- 首次后续消息接续暴露已撤销凭据沿用问题，返回 HTTP 401；已修复并保留失败记录。两个回归覆盖服务刷新凭据与真实 PTY 适配器接续。只恢复受影响分析需求，未重复代码需求或新建成员。
