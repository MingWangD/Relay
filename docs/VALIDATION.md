## 真实三类 CLI 协作

在新建隔离 Git 项目中，由 App 原生选择项目并配置 Codex、Antigravity、Claude 各一名。验证模型分别为 gpt-6.1-sol（low）、gemini-3.8-flash-medium、deepseek-flash（high）；模型可用性受本机 CLI、账号及服务配置影响。

- 一轮代码需求：只新增限定文件，独立测试、非作者交叉评审和安全回写完成；三名成员均参与。平台两条测试退出状态为 0，成员另有真实测试证据。
- 同一团队后续分析需求：四项累计任务均完成，成员原生 ID 不变；分析只交依据，无新平台自动测试，不把分析结果称为测试通过。
- 原项目 HEAD、分支和暂存内容保持。首轮 Git 只读检查刷新了索引统计缓存，已使用 GIT_OPTIONAL_LOCKS=0 修复并增加实际索引字节回归。
- 首次后续消息接续暴露已撤销凭据沿用问题，返回 HTTP 401；已修复并保留失败记录。两个回归覆盖服务刷新凭据与真实 PTY 适配器接续。只恢复受影响分析需求，未重复代码需求或新建成员。
