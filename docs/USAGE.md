# 使用 Relay

## 项目与聊天

启动 App 后，点击项目旁“＋”或按 `⌘⇧P`，选择本机可信 Git 项目。不同 Git 根目录拥有独立控制台、凭据和数据库；再次选择原项目会复用已有空间。选择目录本身不启动模型。

左栏显示未归档聊天；`⌘N` 新建聊天。每个聊天保留自己的成员身份、设置和阅读位置；同一项目共享串行需求队列。需要另起一组原生会话时新建聊天，不通过切换项目复制其他项目的身份。

## 配置团队

空闲时设置 1–8 名成员，可混用 Codex、Antigravity、Claude Code。模型目录由本机 CLI／配置发现，实际可用性由 CLI、账号和服务确认。

- Codex：模型与思考强度分别选择。
- Antigravity：使用完整模型 ID，强度包含在模型名称中，不单独选择 effort。
- Claude Code：原生别名与已配置模型；桌面启动会从用户登录 shell 补齐允许的模型、服务和认证变量。

保存团队只保存设置；发送下一条需求才启动 CLI。执行、排队或待恢复期间不能改团队。目录未出现预期模型时点击“刷新模型目录”，仍缺失时按 [排障指南](TROUBLESHOOTING.md#模型目录缺失或-cli-不可用) 检查。

## 发出需求与查看成果

描述目标、范围和验证要求，不必手工分配角色。Enter 发送，Shift + Enter 换行。执行时可补充要求，也可将下一条作为新需求排队；暂停／继续与停止入口位于输入区附近。

每项需求的“查看协作过程”默认折叠，展开后查看任务、成员交流和真实 CLI 终端。终端文本只供观察；完成状态由持久化事件决定。最终结论位于协作区下方，“查看改动”展示成果差异。

历史阅读保持手动滚动；新消息不抢焦点。点击“查看最新”才跳转。终端普通缓冲使用本地历史，全屏终端使用受限滚轮通道；键盘和粘贴需要先开启“人工接管”。

代码成果经过独立检查、交叉评审和候选整合后回写。Relay 不自动暂存、提交或推送原项目。分析需求只交报告；发现测试入口缺失时应明确说明未执行自动测试。

## 处理审批与恢复

需要登录、风险声明、系统授权或 CLI 原生审批时，查看提醒并打开对应终端。需要输入时开启“人工接管”，处理后退出接管。Relay 不猜测按键替你确认。

服务重启后不会自动重跑旧任务，也不能重新附着旧 PTY。使用“恢复成员”前检查对应旧进程、工作区成果和原生会话；仍存活的进程会阻止恢复。恢复沿用明确的原生 ID，失败不会改用最近会话或另建身份。

网页进程故障可在原生提示中重新加载，或从“查看 → 重新加载页面”（`⌘R`）恢复页面。刷新不是重新派单。若发生文件冲突，保留成果、检查差异，再处理冲突；不要强制覆盖人工修改。

## 数据与权限

新团队默认“完全访问”，可读写当前用户可访问的文件、执行命令和联网，包含项目外目录。选择“原生审批”可按 CLI 流程逐项确认；没有权限字段的旧团队保持原生审批。只修改 Relay 子进程，不更改全局账号或权限。

独立工作区和回写检查不是强制沙箱。分析依赖前后文件审计，无法证明项目外操作或执行中恢复的修改不存在。只使用可信项目；模型的数据处理遵循对应 CLI／服务。

App 默认数据目录为 `~/Library/Application Support/Relay`，源码开发默认 `.local/`。首次启动不会自动复制其他数据；删除 App 不删除数据。

导入流程：

1. 停止源数据目录对应的服务，结束当前 App 内运行事项，并正常保存工作。
2. 选择原生菜单“文件 → 导入现有 Relay 数据”，选完整源数据目录。
3. 核对确认提示；导入前备份原目标数据，源目录不修改。
4. 导入成功后 App 退出。重新打开，再选择所需项目，核对聊天与成员绑定；旧需求不会自动恢复执行。

目录重叠、源服务仍存活或复制失败会阻止导入。具体检查与已验证范围见 [测试指南](TESTING.md) 和 [验收摘要](VALIDATION.md)。

## 归档与快捷键

“更多 → 已归档对话”可搜索、打开、取消归档和删除历史。归档可恢复；删除需确认，仅删 Relay 记录，不删项目和 CLI 全局历史。执行、排队、检查或待恢复时不能归档／删除。

| 快捷键 | 操作                               |
| ------ | ---------------------------------- |
| `⌘K`   | 命令面板                           |
| `⌘N`   | 新建聊天                           |
| `⌘⇧P`  | 选择项目                           |
| `⌃⌘F`  | 进入／退出全屏                     |
| `⌘R`   | 重新加载页面                       |
| `⌘U`   | 检查更新，当前开发版未配置生产更新 |
| `⌘Q`   | 正常退出并停止本地服务             |
| Escape | 关闭菜单或弹窗                     |

关闭最后一个窗口会退出 App。预览版的窗口和快捷键实现与实际验收结果分别记录；尚未验证的原生行为见 [VALIDATION](VALIDATION.md)。

## macOS 快捷键

编辑菜单使用 macOS 当前焦点：⌘C 复制、⌘V 粘贴、⌘X 剪切、⌘A 全选、⌘Z 撤销、⌘⇧Z 重做。适用于聊天输入、设置表单和可编辑原生控件；终端输入仍需开启人工接管。

⌘K 打开命令面板，⌘N 新建聊天，⌘B 显示／隐藏聊天历史，⌘⇧P 选择项目，⌘, 打开设置，⌘W 关闭窗口，⌃⌘F 切换全屏，⌘Q 退出。关闭最后一个窗口会退出 Relay；再次启动可恢复已有聊天记录。

输入中文等组合文字时，回车只确认输入法候选词。确认完成后，再按回车发送；Shift+回车换行。
